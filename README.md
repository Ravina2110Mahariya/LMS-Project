# LMS Project

## Overview

A Learning Management System (LMS) built using Spring Boot and MongoDB.

## Features

* User Authentication (JWT + Spring Security)
- Admin Dashboard
- Student Dashboard
- Instructor Dashboard
- Course Management
- Enrollment Management
- Assignments
- Quiz Module
- Quiz Results
- Progress Tracking
- Attendance
- Certificates
- Reviews & Ratings
- Discussions
- Notes Upload
- Video Upload
- Live Classes
- Notifications
- Reports
- File Upload
* Swagger API Documentation

## Technology Stack

* Java 21
* Spring Boot 3
* Spring Security
* JWT
* MongoDB
* Thymeleaf
* Swagger OpenAPI
* JUnit 5
* Mockito
* Maven
* rest-api
* bootstrap
* lms

* learning-management-system
